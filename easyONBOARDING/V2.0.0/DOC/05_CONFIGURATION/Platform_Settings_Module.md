# Plattform-Einstellungen

Dieses Dokument beschreibt den Zweck der Einstellungsseite innerhalb von `easyONBOARDING V2.0.0`.

## Fokus der Seite

Die Plattformsteuerung bündelt die fachlichen und technischen Konfigurationsdomänen der Anwendung.

## Aktuelle Themenblöcke

- Mandanten und Branding
- Module und Connectoren
- Security und Audit

## Später geplanter Ausbau

- Pflege von Domänen, Logos und Standardwerten
- Aktivierung und Health-Prüfung einzelner Connectoren
- Steuerung von Freigaben und Richtlinien
- Konfiguration technischer Zielsysteme
- Verwaltung von Audit- und Exportregeln

## Betriebsgrundsatz

Änderungen an zentralen Plattformwerten sollen später nachvollziehbar, rollenbasiert abgesichert und revisionsfähig dokumentiert werden.
